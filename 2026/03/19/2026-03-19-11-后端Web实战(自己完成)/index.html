2. 需求：班级管理

需要开发如下几个接口，且开发的时候建议按照如下顺序开发 ：

2.1 条件分页查询接口

参照接口文档 班级管理 -> 班级列表查询

注意：班级状态，显示为：未开班、已结课、在读中 这三种。

如果：

  • 当前时间 > 结课时间：状态未 已结课。

  • 当前时间 < 开课时间：状态未 未开班。

  • 否则，就是 在读中。

2.2 查询所有员工接口

那其实，对于培训机构来说，班主任就是这个企业的员工。所以，班主任下拉列表中展示的就是所有的员工数据。

参照接口文档 员工管理 -> 查询全部员工

2.3 新增班级信息接口

参照接口文档 班级管理 -> 添加班级

2.4 根据ID查询班级接口

参照接口文档 班级管理 -> 根据ID查询

2.5 修改班级信息接口

参照接口文档 班级管理 -> 修改班级

2.6 删除班级信息接口

参照接口文档 班级管理 -> 删除班级

注意：在页面原型中，要求如果该班级下关联的有学生，是不允许删除的，并提示错误信息：”对不起, 该班级下有学生, 不能直接删除”。 (提示：可以通过自定义异常 + 全局异常处理器实现)

到此，关于班级管理的增删改查功能，我们就已经全部实现了。

3. 需求：学员管理

需要开发如下几个接口，建议按照如下顺序开发接口：

3.1 查询所有班级接口

参照接口文档 班级管理 -> 查询所有班级

在新增学员的时候，要展示出所有的班级信息。

3.2 条件分页查询接口

参照接口文档 学员管理 -> 学员列表查询

3.3 新增学生信息接口

参照接口文档 学员管理 -> 添加学员

3.4 根据ID查询学生接口

参照接口文档 学员管理 -> 根据ID查询学员

3.5 修改学生信息接口

参照接口文档 学员管理 -> 修改学员

3.6 删除学生信息接口

参照接口文档 学员管理 -> 删除学员

3.7 违纪处理接口

参照接口文档 学员管理 -> 违纪处理

违纪处理一次，需要将违纪次数+1，违纪扣分+前端输入的分数。

到此，关于学生管理的增删改查功能，我们就已经全部实现了。

4. 需求：学员信息统计

需要开发如下几个接口：

  • 班级人数统计接口开发：参照接口文档 数据统计 -> 班级人数统计

  • 学员学历信息统计接口开发：参照接口文档 数据统计 -> 学员学历统计

5. 需求：功能完善

  • 删除部门时： 如果部门下有员工，则不允许删除该部门，并给前端提示错误信息：对不起，当前部门下有员工，不能直接删除！
