# 2. 无限试用激活 （稳定）
Jrebel 采用试用的方式：通过采集机器码、取idea、插件等信息方式生成试用密钥。
方法：
* 访问： https://www.jpy.wang/page/jrebel.html , 获得下面命令行
```
curl https://register.jpy.wang/ReRegister/src/main/java/jrebel/JrebelMain.java -o tmp.java && java tmp.java && del tmp.java
```

* 复制到命令提示符进行执行 : (运行(win+r) -> cmd -> 粘贴上面命令) ,
![](https://smith-1315833455.cos.ap-beijing.myqcloud.com/blog/d36296d9a26e46a7a03ee08ffcb3318f.png)

* 点击 Get License 按钮进行一键激活， 程序会自动虚拟设备id和环境，获取试用key并存入idea 插件的缓存目录里。
* 重启 idea , 点同意即可正常jrebel插件。
**试用期到期,可循环以上操作达到无限使用的目的。**
注意： *本方法主要是运用到在线运行java源码的能力
* curl 命令需要 win10 或 win11，且建议使用 Windows专业版。
* 需要jdk11 以上
> 特性 (shell) , 通过curl 下载源码并传递源码文件给java执行，无需编译class，直接跑UI。
> 特性 (java.net.http.HttpRequest) , 无需三方库jdk自带网络请求类，减小代码体积。
* 如果系统里有多版本jdk，可以修改上面的命令
```
curl https://register.jpy.wang/ReRegister/src/main/java/jrebel/JrebelMain.java -o tmp.java && c:/jdk-11/bin/java tmp.java && del tmp.java
```
*如果系统不支持curl命令，可将源码下载到本地，通过idea运行。(推荐在线跑源码,随作者保持更新)
