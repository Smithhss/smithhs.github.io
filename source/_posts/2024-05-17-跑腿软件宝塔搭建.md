# 后端

伪静态 thinkphp
导入数据库
数据库修改.env

```
[DATABASE]
TYPE = mysql
HOSTNAME = 127.0.0.1
DATABASE = 数据库名
USERNAME = 数据库名
PASSWORD = 数据库密码
HOSTPORT = 3306
CHARSET = utf8
DEBUG = true
/config/database.php）
```
